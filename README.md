## Features

This website is designed to provide the best possible developer experience when exploring the `react-ripple` library.

* **Interactive Demo Cards**: Test out different ripple configurations (Auto Theme, Forced Light/Dark, Custom Colors) in real-time.
* **Multi-Framework Snippets**: View and copy implementation code for **React**, **Vue 3**, **Svelte**, and **Vanilla JS**.
* **Live Documentation**: Automatically fetches and renders the latest `README.md` from the core repository.
* **Smart ScrollSpy Navigation**: Reads Markdown headers dynamically to create an auto-highlighting table of contents.
* **Fluid Animations**: Powered by **Framer Motion** for silky smooth page transitions, staggered reveals, and Apple-like segmented controls.
* **Dark & Light Mode**: Seamless theme switching that also adapts the syntax highlighter theme automatically.

## คุณสมบัติ (Thai)

เว็บไซต์นี้ถูกออกแบบมาเพื่อให้นักพัฒนาได้ทดลองเล่นและดูตัวอย่างการใช้งานไลบรารีได้ง่ายและสวยงามที่สุด

* **Interactive Demo Cards**: ทดลองคลิกเพื่อดูเอฟเฟกต์ Ripple ในรูปแบบต่างๆ ได้ทันที (Auto Theme, โทนสว่าง, โทนมืด, หรือเปลี่ยนสีเอง)
* **รองรับหลาย Framework**: มีโค้ดตัวอย่างที่พร้อมก๊อปปี้ไปใช้งานได้ทั้ง **React**, **Vue 3**, **Svelte** และ **Vanilla JS**
* **Live Documentation**: ระบบดึงคู่มือการใช้งาน (`README.md`) มาจาก Github ของตัวไลบรารีหลักแบบอัตโนมัติ 
* **Smart ScrollSpy Navigation**: มีแถบเมนูด้านซ้ายที่จะไฮไลท์หัวข้อตามที่เรากำลังเลื่อนอ่านอยู่
* **แอนิเมชันสุดสมูท**: จัดเต็มด้วย **Framer Motion** ทั้งการสลับหน้า, ปุ่ม Segmented Control ที่สไลด์ได้แบบแอปเปิล และ Staggered Reveal
* **รองรับ Dark / Light Mode**: สลับธีมมืด/สว่างได้ลื่นไหล ซึ่งตัวสีของโค้ด (Syntax Highlighter) ก็จะเปลี่ยนตามไปด้วยแบบอัตโนมัติ

## Tech Stack

* **Framework**: React + Vite
* **Styling**: Tailwind CSS
* **Animations**: Framer Motion
* **Icons**: Lucide React
* **Markdown Parsing**: React Markdown + Remark GFM
* **Syntax Highlighting**: React Syntax Highlighter (Prism)

## Getting Started (วิธีรันโปรเจ็กต์)

To run this showcase website locally / วิธีรันโปรเจ็กต์นี้ในเครื่อง:

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/DoNuTll40/react-ripple-showcase.git](https://github.com/DoNuTll40/react-ripple-showcase.git)
    cd react-ripple-showcase
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```
